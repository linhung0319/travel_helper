# 時刻表（data/timetables/）

T10（2026-10-19）整理。近鐵（`kintetsu/`）是 T1 做的，這份說明只講 T10 的巴士、船、JR。

| 目錄 | 內容 | 怎麼產生 |
|---|---|---|
| `bus/<route-id>.json` | 三重交通、鳥羽市かもめバス、志摩市安乗線代替交通，15 條 | `node scripts/gtfs-timetable.mjs` |
| `ferry/<route-id>.json` | 鳥羽市営定期船 5 條、あご湾定期船 1 條 | 同上 |
| `jr/jr-sangu.json` | JR 參宮線 伊勢市～鳥羽（路線格式，和巴士、船相同） | `node scripts/jr-timetable.mjs` |
| `jr/<station-id>.json` | JR 5 站的發車時刻表（沿用近鐵時刻表的格式，方向 `for-toba`、`for-taki`） | 同上 |

查詢：`node scripts/next-bus.mjs <A> <B> <YYYY-MM-DD> <HH:MM>`，A、B 可以是車站或景點的 ID（例如 `isuzugawa ise-naiku`、`toba-sadahama-marine-terminal toba-port-kamishima`、`jr-iseshi jr-futaminoura`）。只找直達，轉乘分段查；步行到停留所的時間沒有算進去。

## 來源

- **巴士、船：GTFS-JP 開放資料**（gtfs-data.jp，授權 CC BY 4.0）。三重交通（伊勢営業所、志摩営業所）、鳥羽市（かもめバス、市営定期船）、志摩市（あご湾定期船、安乗線代替交通）都有公開。每個檔案的 `feed.credit` 是要標示的出處，**T11 網站顯示這些資料時要附上**。
- **JR：JR おでかけネット「区間時刻表」**（JR 西日本，robots.txt 全部允許）。每班車在各站的到發時刻都有。
  - 沒用 ekitan：它的土曜、休日時刻表要帶查詢參數，robots.txt 禁止。
  - 沒用 Yahoo!路線情報：robots.txt 禁止 Claude。
  - 沒用 jorudan：回傳「アクセスが集中しています」。
- 兒童票、5day plus、注意事項：讀官網（2026-10-19），寫在兩支腳本開頭的設定裡（`FEEDS`、`ROUTE_NOTES`、`FARES`、`NOTES`）。改這些要改腳本再重跑，不要手改 JSON，否則下次重跑會被蓋掉。

## 旅程日期怎麼對到時刻表（`dayTypeBasis`）

日別分 `weekday`（平日）、`saturday`（土曜）、`holiday`（日曜和國定假日；旅程中 2/11 是國定假日）。三重交通、かもめバス、市営定期船的 GTFS 都在國定假日跑日祝的班次。

資料還沒涵蓋 2027 年 2 月的：
- **三重交通 GTFS**：每天自動更新，只到約 3 個月後（這次到 2027-01-19）。
- **JR おでかけネット**：只查得到約 2 個月內（這次用 2026-12）。

這兩個用資料裡「同星期幾、不是國定假日或年末年始」的最近一天推算。每個檔案的 `dayTypeBasis` 寫明旅程每天是用哪一天推算的，`next-bus.mjs` 會在結果後面標「推算」。

かもめバス（到 2027-03-31）、市営定期船（到 2028-01-31）、あご湾定期船（到 2027-09-30）、安乗線代替交通（到 2027-03-28）已經涵蓋旅程日期，用的是實際日期。

**2027 年 1 月中旬要重跑兩支腳本**（`--refresh` 重新下載 GTFS），屆時 2 月的實際班次應該已經公開，三重交通 2026-12-14 的票價調整也會反映進去。

## 路線怎麼挑的

從 `areas/*/spots.json` 挑出離車站步行超過 15 分、或 `access` 寫巴士或船的景點，找它們 1 km 內的停留所（船是 1.5 km），再挑出經過這些停留所、也經過近鐵車站的路線。

| 路線 ID | 主要服務的景點 |
|---|---|
| `sanco-gaiku-naiku-chokokan`、`sanco-gaiku-naiku-chosha` | 外宮、內宮、おはらい町、猿田彦神社、月讀宮、神宮徵古館（51、55 系統） |
| `sanco-canbus` | 五十鈴川站、內宮、二見（夫婦岩、伊勢シーパラダイス）、鳥羽水族館 |
| `sanco-ise-shinai-a`、`sanco-ise-shinai-b` | 內宮、猿田彦神社、松尾觀音寺 |
| `sanco-ise-toba` | 伊勢市站～二見～鳥羽、河崎 |
| `sanco-sangu` | 朝熊山頂、金剛證寺（**只有土日祝**） |
| `sanco-goza` | 大王埼燈塔、波切、大王支所、あづり浜、御座（パールミキ） |
| `sanco-shukuura` | 濱島（いわほ觀光汽船）、横山展望台（鵜方浜）、天の岩戸口 |
| `sanco-anori`、`shima-anori-daitai` | 渡鹿野渡船場（的矢灣遊覽）、安乘埼燈塔（代替交通**只有日祝**） |
| `kamome-1`、`kamome-2`、`kamome-4`、`kamome-5` | 海の博物館、鳥羽展望台、相差（石神さん、海女小屋）、國崎（鎧埼燈塔）、伊射波神社 |
| `toba-teikisen-*` | 答志島（和具、答志）、桃取、菅島、神島、坂手 |
| `ago-teikisen` | 間崎島（賢島港～間崎～和具） |

`stops[].near` 是**直線距離**，不是步行時間。下面兩個景點直線距離近，實際要走山路：
- **横山展望台**：鵜方浜站直線 780 m，但要走登山步道 35～45 分。
- **伊射波神社**：ウィスタリアン前站直線 640 m，但要走森林參道 30～40 分。

詳見景點資料的 `access`。

**沒有巴士或船可以到的景點**（要搭計程車、店家接送或包車）：
- 海ほおずき：資料寫「浜島」下車步行 20 分，但 GTFS 的停留所都在 1 km 以外。
- 天の岩戸：天の岩戸口站超過 1 km，下車後步行約 20 分。
- 真珠の里：要事先打電話請店家接送（從越賀站，或從和具港；和具港可以搭 `ago-teikisen`）。
- ともやま公園
- 志摩自然学校
- 春雨展望台（菅崎園地）
- 志摩地中海村：鵜方站的接駁車以住宿客優先，日歸不能預約；或從賢島搭海上計程車（Entrada）。

## 待確認（出發前或排到這些路線時）

- [ ] **三重交通票價調整**：2026-09-10 公告「路線バス（乗合バス）の運賃変更について」，數字看起來是 2026-12-14 起調漲（例如 200→210 円）。公告的 PDF 這次讀不到文字（https://www.sanco.co.jp/sancowp/images/release260910.pdf ），要人工確認。檔案裡的票價是 GTFS（2026-10）的，可能是調整前。
- [ ] **参宮バス**：官網頁面還是 2015 年的。GTFS 只有土曜、日祝班次，和官網一致，但 2026 年度的票價要確認（GTFS 是 1,000 円，官網舊頁 900 円）。
- [ ] **安乗線代替交通**：志摩市營運、只在日祝行駛。為什麼有替代交通，官網找不到說明；5day plus 能不能搭也不明。
- [ ] **市営定期船的兒童票金額**：在運賃表 PDF 裡，沒讀到。
- [ ] **JR 伊勢市～鳥羽的票價**：沒查到。伊勢市～二見浦、二見浦～鳥羽各 210 円是 ekitan 的資料（非官方）。
- [ ] **CANばす冬季**：有沒有減班官網沒寫。目前 GTFS 是每天約 1 小時 1 班。
- [ ] **5day plus 的範圍**：官網只寫「伊勢志摩地區的三重交通巴士」，CANばす、参宮バス這類觀光路線有沒有例外不明。各檔的 `passes` 先標 true。
