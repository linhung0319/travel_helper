## 結論摘要
- **第一天**：13:20 那批落地、約 14:20～14:35 出關（推估），搭 14:35 ラピート → 16:10 大阪難波發的近鐵特急（直達賢島的最後一班），18:35 到鵜方、18:40 到賢島。趕不上就搭 17:10 到鳥羽轉車，20:16 到鵜方。不需要途中過夜。
- **會合**：建議第一批在機場等，全員一起走。
- **最後一天**：從伊勢市要搭 06:07～06:24 的特急，太早。建議 2/12 住大阪難波或關西機場附近。
- **行李**：機場宅配到三重最快隔天到，第一天自己帶；中途換住宿用伊勢市站、鳥羽站的當日配送；回程可以 2/11 寄空港宅急便。

## 排除的選項
- JR（はるか＋新幹線＋名古屋）、快速みえ、JR 関西本線：慢、轉乘多。
- 高速巴士：關西機場、大阪沒有直達伊勢志摩的路線。
