# T31 自己加地點 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 家人可以從探索的搜尋框（Google Maps 連結、日本地址、找不到的店名）或地圖上指位置，自己加一個地點；加好的點和一般的點一起出現在地圖、清單、詳情，但看得出來是「自己加的、沒查過」。

**Architecture:** 純函式（網址解析、輸入分類、國土地理院、重複判斷、轉成 `Place`）放 `web/src/lib/addPlace/`；後端介面加上 user places（假後端照 Worker 規則）；自己加的點在 `sharedStore` 載入後轉成 `Place` 併進 `dataStore.places`，所以列表、地圖、搜尋、詳情都自動看得到。確認畫面的草稿狀態放在新的 `web/src/addPlaceStore.ts`，手機（整頁＋自己的小地圖）和網頁（右欄表單＋主地圖可拖的圖釘）共用。

**Tech Stack:** React 18、TypeScript、Zustand（vanilla store）、MapLibre GL、Cloudflare Worker、`node --test`、Playwright。

**Spec:** `docs/superpowers/specs/2026-10-30-add-place-design.md`（每個任務都要先讀它的相關段落）
