# 統一樣式、去掉重複入口、篩選、想去、詳情、拖曳、地圖標示：實作計畫（T15m 第七輪）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 手機版、網頁版用同一套樣式和元件，每個功能只有一個入口；篩選、想去、詳情、時間軸卡片、拖曳、地圖標示照第七輪設計重做。

**Architecture:**
- 樣式：`styles.css` 的 `:root` 是唯一的 token 來源；`mobile.css`、`chat.css` 只用變數。圖示是 `components/Icon.tsx`（行內 SVG path）。
- 兩邊共用的規則是純函式，放 `web/src/shared/`、`web/src/lib/`，有單元測試（`web/test/*.test.ts`，`npm test`）。
- 兩邊共用的畫面元件放新的 `web/src/shared/ui/`；網頁版元件在 `components/`、手機版在 `mobile/`，都改用共用元件。
- 地圖：`MapView.tsx` 的選中標示換成一個「數字水滴」圖層；移動地圖的判斷抽成純函式 `lib/mapCamera.ts`。

**Tech Stack:** TypeScript、React 19、Zustand vanilla、MapLibre、node:test、Playwright。

**Spec:** `docs/superpowers/specs/2026-10-26-ui-round7-design.md`。草圖：https://claude.ai/artifact/MG6YiDedGfEZVq4iJvAoa2 （原始檔 `data/cache/work/t15m-audit/review.html`，在主 repo `D:\workspace\travel_helper` 底下，不進 git）。**草圖和設計文件不一樣的地方，以設計文件為準。**
